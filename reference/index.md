# Package index

## Data

Fixed, checksummed datasets with provenance and validation.

- [`btg_datasets()`](https://blackthrive.github.io/BlackThriveSS/reference/btg_datasets.md)
  : Discover bundled dashboard datasets
- [`btg_releases()`](https://blackthrive.github.io/BlackThriveSS/reference/btg_releases.md)
  : List fixed releases available offline
- [`btg_get_data()`](https://blackthrive.github.io/BlackThriveSS/reference/btg_get_data.md)
  : Read a fixed dashboard dataset with coverage and provenance
- [`btg_metadata()`](https://blackthrive.github.io/BlackThriveSS/reference/btg_metadata.md)
  : Inspect snapshot provenance
- [`btg_coverage()`](https://blackthrive.github.io/BlackThriveSS/reference/btg_coverage.md)
  : Inspect monthly submission coverage
- [`btg_validate()`](https://blackthrive.github.io/BlackThriveSS/reference/btg_validate.md)
  : Validate the integrity and internal consistency of a fixed dataset
- [`btg_citation()`](https://blackthrive.github.io/BlackThriveSS/reference/btg_citation.md)
  : Cite a fixed evidence release
- [`btg_export()`](https://blackthrive.github.io/BlackThriveSS/reference/btg_export.md)
  : Export a dataset with its provenance
- [`btg_glossary()`](https://blackthrive.github.io/BlackThriveSS/reference/btg_glossary.md)
  : The terms BlackThriveSS uses

## Charts

Editable ggplots that carry their table and a replayable view.

- [`btg_plot_disparity()`](https://blackthrive.github.io/BlackThriveSS/reference/btg_plot_disparity.md)
  : Reproduce the dashboard's force ranking as an editable plot
- [`btg_plot_sensitivity()`](https://blackthrive.github.io/BlackThriveSS/reference/btg_plot_sensitivity.md)
  : Chart how robust each displayed force's comparison is
- [`btg_plot_trend()`](https://blackthrive.github.io/BlackThriveSS/reference/btg_plot_trend.md)
  : Chart a series over time from a bundled dataset
- [`btg_plot_change()`](https://blackthrive.github.io/BlackThriveSS/reference/btg_plot_change.md)
  : Chart how forces' stop-rate ratios changed between two years
- [`btg_figure_data()`](https://blackthrive.github.io/BlackThriveSS/reference/btg_figure_data.md)
  : Extract the original numerical table behind a chart
- [`btg_theme()`](https://blackthrive.github.io/BlackThriveSS/reference/btg_theme.md)
  : The ggplot2 theme BlackThriveSS charts use
- [`btg_colours()`](https://blackthrive.github.io/BlackThriveSS/reference/btg_colours.md)
  : The colours BlackThriveSS charts use
- [`btg_group_colours()`](https://blackthrive.github.io/BlackThriveSS/reference/btg_group_colours.md)
  : The colours BlackThriveSS uses for ethnic groups

## Robustness and change

What a comparison rests on, with sampling and assumptions kept apart.

- [`btg_sensitivity()`](https://blackthrive.github.io/BlackThriveSS/reference/btg_sensitivity.md)
  : Bound a comparison under every allocation of unknown-ethnicity stops
- [`btg_rank_stability()`](https://blackthrive.github.io/BlackThriveSS/reference/btg_rank_stability.md)
  : Estimate how stable each force's rank is under sampling variability
- [`btg_robustness_summary()`](https://blackthrive.github.io/BlackThriveSS/reference/btg_robustness_summary.md)
  : Summarise robustness across every year and group
- [`btg_change()`](https://blackthrive.github.io/BlackThriveSS/reference/btg_change.md)
  : Change in stop-rate ratios between two years
- [`btg_source_status()`](https://blackthrive.github.io/BlackThriveSS/reference/btg_source_status.md)
  : Check the bundled snapshot against the live Police.uk source

- [`btg_report()`](https://blackthrive.github.io/BlackThriveSS/reference/btg_report.md)
