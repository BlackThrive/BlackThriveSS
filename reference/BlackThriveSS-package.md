# BlackThriveSS: Reproducible Dashboard Evidence

Start with
[`btg_get_data()`](https://blackthrive.github.io/BlackThriveSS/reference/btg_get_data.md)
and
[`btg_plot_disparity()`](https://blackthrive.github.io/BlackThriveSS/reference/btg_plot_disparity.md).
Inspect provenance with
[`btg_metadata()`](https://blackthrive.github.io/BlackThriveSS/reference/btg_metadata.md),
reporting coverage with
[`btg_coverage()`](https://blackthrive.github.io/BlackThriveSS/reference/btg_coverage.md),
and chart values with
[`btg_figure_data()`](https://blackthrive.github.io/BlackThriveSS/reference/btg_figure_data.md).
Use
[`btg_save_view()`](https://blackthrive.github.io/BlackThriveSS/reference/btg_save_view.md)
and
[`btg_from_view()`](https://blackthrive.github.io/BlackThriveSS/reference/btg_from_view.md)
to replay the original evidence specification offline. Inspect internal
consistency with
[`btg_validate()`](https://blackthrive.github.io/BlackThriveSS/reference/btg_validate.md).
The installed tutorial is available through
[`vignette("getting-started", package = "BlackThriveSS")`](https://blackthrive.github.io/BlackThriveSS/articles/getting-started.md).
